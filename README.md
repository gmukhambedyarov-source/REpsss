# Семейный альбом

Самостоятельно размещаемое веб-приложение для хранения фотографий и видео всей семьи.
Работает в браузере на компьютере и телефоне, данные хранятся у вас — на домашнем
сервере, NAS или VPS.

## Возможности

- **Загрузка фото и видео** — кнопкой или перетаскиванием в окно, пачками, с прогрессом.
  Превью создаются прямо в браузере, дубликаты распознаются автоматически (по SHA-256).
- **Лента** с группировкой по дням, бесконечной прокруткой, фильтрами «Фото/Видео»,
  диапазоном дат и сортировкой.
- **EXIF**: дата съёмки, камера и GPS-координаты извлекаются автоматически
  (ссылка «Показать на карте»).
- **Альбомы** с описанием, обложкой, датами события и слайд-шоу.
- **Публичные ссылки на альбом** — родственники без аккаунта могут смотреть и скачивать;
  доступ можно закрыть в один клик.
- **Люди и теги** — отмечайте, кто на фото, и находите все снимки человека.
- **Избранное** — у каждого члена семьи своё.
- **Комментарии** под каждым фото и видео.
- **Просмотрщик**: стрелки/свайпы, слайд-шоу на весь экран, скачивание оригинала,
  редактирование названия, описания и даты.
- **Воспоминания «В этот день»** — снимки, сделанные в этот день в прошлые годы.
- **Мультивыбор** (клик по кружку, Shift — диапазон, долгое нажатие на телефоне):
  добавить в альбом, отметить человека, тег, избранное, скачать, удалить.
- **Корзина** — удалённое хранится 30 дней, затем удаляется автоматически.
- **Поиск** по названиям, описаниям, именам файлов, людям, тегам, альбомам и камере.
- **Семья**: приглашения по ссылке, роли (администратор / участник / только просмотр),
  статистика по годам и участникам, смена пароля.
- Светлая и тёмная тема, адаптивный интерфейс, можно установить как приложение (PWA).

## Запуск

Нужен Node.js 22.13 или новее (используется встроенный `node:sqlite`, внешняя база не нужна).

```bash
npm install
npm start
```

Откройте http://localhost:3000 — первый зарегистрированный пользователь становится
администратором. Остальных членов семьи приглашайте в разделе **«Семья» → «Приглашения»**.

### Docker

```bash
docker compose up -d
```

Все данные (база и файлы) окажутся в папке `./data` рядом с `docker-compose.yml`.

### Настройки (переменные окружения)

| Переменная      | По умолчанию | Назначение                                   |
|-----------------|--------------|----------------------------------------------|
| `PORT`          | `3000`       | Порт HTTP-сервера                             |
| `HOST`          | `0.0.0.0`    | Адрес, на котором слушает сервер             |
| `DATA_DIR`      | `./data`     | Где хранить базу, оригиналы и превью         |
| `MAX_UPLOAD_MB` | `4096`       | Максимальный размер одного файла, МБ         |
| `TRUST_PROXY`   | —            | Установите `1`, если приложение за reverse proxy (nginx, Caddy) |

Для доступа из интернета поставьте перед приложением reverse proxy с HTTPS
(например, Caddy) и увеличьте в нём лимит размера запроса.

## Резервное копирование

Всё хранится в `DATA_DIR`:

```
data/
  album.db            — база: пользователи, альбомы, теги, комментарии
  originals/ГГГГ/ММ/  — оригиналы файлов, разложенные по дате съёмки
  thumbs/             — превью
```

Достаточно регулярно копировать эту папку целиком (например, `rsync` или `restic`).

## Разработка

```bash
npm run dev   # перезапуск сервера при изменениях
npm test      # тесты API
```

Структура:

```
server/            Express-сервер
  app.js           сборка приложения, очистка корзины
  db.js            схема SQLite
  auth.js          пароли (scrypt), сессии, роли
  media-helpers.js выборка и сериализация медиа, теги/люди
  routes/          auth, media, albums, library (теги, статистика, публичные ссылки)
public/            интерфейс без сборки (ES-модули)
  js/app.js        маршрутизация и разделы
  js/grid.js       сетка с группировкой и мультивыбором
  js/viewer.js     полноэкранный просмотр, слайд-шоу, детали, комментарии
  js/upload.js     очередь загрузки и создание превью
test/              тесты API (node:test)
```
